# 2026-09-13 — Memoria de `forge-termd` con 50 terminales

```sh
cargo build --release -p proto-termd -p forge-bench
cargo run --release -p forge-bench -- termd_idle --iterations 50 --check
```

El escenario levanta un daemon privado, crea 50 PTYs de 80×24 con un proceso
inactivo y mide el PSS de `proto-termd` desde `/proc/<pid>/smaps_rollup`. Los
procesos hijo se excluyen para aislar el coste de Forge. El benchmark mata el
daemon y limpia el socket al terminar.

El resultado JSON reproducible se genera con `--output`; estos archivos crudos
se mantienen fuera de Git y este documento conserva la evidencia estable.

Esta medición pasa la puerta intermedia de 50 sesiones. No sustituye la puerta
final de Fase 2: 200 terminales en R1 con PSS total de `termd` ≤ 100 MiB.
